Step 2: 포트 배정 및 Windows 호스트 연동 (Port Assignment)

충돌 없는 난수 고위 포트를 안전하게 배정하고, 호스트 PC의 포트포워딩 설정 스크립트를 생성합니다.

외부로 직접 노출되지 않으며, Cloudflare Tunnel을 통해서만 안전하게 중계됩니다.
모바일 기기가 Windows 호스트로 접근할 외부 포트입니다. (기본 SSH 22 포트 점유 충돌 방지)
📥 Windows 호스트 원클릭 설정 배치파일 (.bat)

Windows에서 포트포워딩과 방화벽 허용 규칙을 1초 만에 자동 등록하는 스크립트입니다.

수동 실행 명령어 (Windows PowerShell 관리자 권한) 
netsh interface portproxy add v4tov4 listenport=29482 listenaddress=0.0.0.0 connectport=22 connectaddress=%WSL_IP%
💡 배치파일 실행이나 포트 설정 중 막히셨나요?
AGY CLI에게 물어보면 현재 포트 및 네트워크 상태를 분석하여 해결책을 찾아줍니다.

Step 4: 도메인 & Cloudflare Tunnel 연동 (Domain & Zero Trust)

          
공유기 포트포워딩이나 공인 IP 노출 없이, 무료 Cloudflare Zero Trust 보안 터널로 도메인(HTTPS)을 연결합니다.

        

        

          

            🔒
            보안 철칙: 본 시스템은 공유기 포트 개방 없이 철저히 Cloudflare Zero Trust 보안 터널(도메인 HTTPS)을 통해서만 안전하게 브라우저 화면을 제공합니다.
          


          
          

            

              🌐 Cloudflare Tunnel 무료 토큰 발급 3단계 퀵 가이드
              대시보드 바로가기 ↗
            

            
    
              
  1. Cloudflare Zero Trust 대시보드 접속 ➔ 좌측 [Networks] ➔ [Tunnels] ➔ [Create a tunnel] 클릭
    2. 
              
  2. 터널 이름(예: wsl-agy) 입력 후 Connector 선택 화면에서 [Docker] 또는 [Debian 64-bit] 선택 ➔ 화면에 나타나는 긴 토큰 문자열(eyJhIjoi...)을 복사하여 아래에 붙여넣기
    3. 
              
  3. [Public Hostnames] 탭에서 [Add a public hostname] 클릭 ➔ 도메인(예: myterminal.mydomain.com), Service: HTTP, URL: localhost:(배정된 ttyd포트) 저장
    4. 
            

          


          

            
            
          


          

            
            
            입력된 토큰은 외부로 전송되지 않으며, 사용자 로컬 머신의 ~/.config/systemd/user/cloudflared.service에만 안전하게 템플릿화됩니다.
          


          

            
            
          


          

            

              💡 토큰 검증에 실패했거나 Cloudflare 연동이 막히셨나요?

              AGY CLI에게 질문하면 터널 로그와 설정 파일 상태를 즉시 점검해 줍니다.
            

            
          

        

      


      
      

        

          
Step 5: Read-Only Web 터미널 서비스 배포 (Service Activation)

          
이전 단계에서 설정된 값들을 바탕으로 템플릿을 생성하고 백그라운드 systemd 서비스를 등록합니다.

        

        

          

            

              

              

                ttyd.service
                옵션: -R (Read-Only) 모드로 브라우저에서 안전한 화면 조회 전용 보장
              

              Ready
            

            

              

              

                cloudflared.service
                옵션: --protocol http2로 방화벽 차단 회피 및 Zero Trust 인그레스 유지
              

              Ready
            

            

              

              

                loginctl enable-linger
                WSL 창을 닫아도 백그라운드 세션 및 데몬이 정지되지 않고 24시간 상시 지속
              

              Ready
            

          


          

            
          


          


          

            

              💡 서비스 기동 중 에러나 포트 충돌이 발생했나요?

              AGY CLI에게 프롬프트를 보내면 `systemctl --user status` 및 포트 점유를 직접 진단/복구합니다.
            

            
          

        

      


      
      

        

          
Step 6: 모바일 KeyBridge 앱 페어링 & 가이드 (Mobile Setup)

          
스마트폰의 KeyBridge 앱과 WSL 시스템을 안전하게 연결하기 위한 SSH 키페어 및 설정을 생성합니다.

        

        

          

            

              

                
              

              
스마트폰 카메라 또는 KeyBridge 앱으로 스캔하세요

            

            

              
모바일 앱 연결 설정 정보

              

                접속 호스트 (Host):
                PC 로컬 IP (예: 192.168.0.x 또는 Tailscale IP)
              

              ※ 주의: Cloudflare 도메인은 웹 브라우저 관제 전용이며, SSH 포트에는 연결되지 않습니다. 스마트폰과 PC가 같은 Wi-Fi에 있을 때는 PC의 로컬 IP(192.168.x.x)를 입력하세요.
              

                SSH 외부 포트:
                29482
              

              

                사용자명 (Username):
                $USER
              

              

                인증 방식:
                Ed25519 전용 키페어 자동 생성
              

              

                
              

            

          


          

            
📱

            

              Donagy KeyBridge 안드로이드 앱 설치
              
물리 블루투스 키보드 신호를 가로채 WSL에 실시간 전달하는 0.1ms 무지연 브릿지 앱입니다.

              💡 모바일 연결 시 Permission Denied나 연결 불가 오류가 발생했나요?
