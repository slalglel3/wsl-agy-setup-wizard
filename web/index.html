Step 1: 환경 자동 진단 (System Inspection)

Step 2: 네트워크 및 난수 포트 자동 배정 (Port Allocation)

개인화 포트 노출을 방지하고 충돌을 피하기 위해 20000~60000 대역의 미사용 포트를 무작위로 자동 추천합니다.

웹 대시보드 (ttyd)

Cloudflare Tunnel을 통해 브라우저로 중계될 로컬 포트입니다.

모바일 SSH 접속

스마트폰 물리 키보드 앱(KeyBridge)이 WSL로 직결할 외부 포트입니다.

Windows 호스트 자동 포트포워딩 명령 (PortProxy) 
netsh interface portproxy add v4tov4 listenport=29482 listenaddress=0.0.0.0 connectport=22 connectaddress=127.0.0.1

Step 4: 도메인 & Cloudflare Tunnel 연동 (Domain & Zero Trust)

          
공유기 포트포워딩이나 공인 IP 노출 없이, 무료 Cloudflare Tunnel로 안전한 HTTPS 주소를 연결합니다.

        

        

          

            

              
A

              

                도메인 준비
                
Cloudflare Registrar, 가비아, Namecheap 등에서 원하는 도메인을 구매하거나 보유한 도메인을 Cloudflare에 등록합니다.

              

            

            

              
B

              

                Cloudflare Zero Trust 대시보드 ➔ Networks ➔ Tunnels 생성
                
무료 터널을 생성하고 발급받은 Install and run a connector 토큰을 복사합니다.

              

            

          


          

            
            
          


          

            
            
            입력된 토큰은 외부로 전송되지 않으며, 사용자 로컬 머신의 systemd 유닛에만 안전하게 템플릿화됩니다.
          


          

            
            
          

        

      


      
      

        

          
Step 5: Read-Only Web 터미널 서비스 배포 (Service Activation)

          
이전 단계에서 설정된 값들을 바탕으로 템플릿을 생성하고 백그라운드 systemd 서비스를 등록합니다.

        

        

          

            

              

              

                ttyd.service
                옵션: -R (Read-Only) 모드로 브라우저에서 안전한 화면 조회 전용 보장
              

              Active
            

            

              

              

                cloudflared.service
                HTTPS ➔ 로컬 ttyd 포트 연결 터널 상시 기동
              

              Active
            

            

              

              

                loginctl linger ($USER)
                WSL 창을 닫아도 백그라운드 프로세스가 영구 유지되도록 등록
              

              Enabled
